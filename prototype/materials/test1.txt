Python functions

A function is a reusable block of code defined with the def keyword. A
function definition may include parameters, which are names for values the
function receives when it is called. The values supplied in a call are
arguments.

The return statement sends a value back to the code that called the function.
If a function reaches the end of its body without executing a return
statement, Python returns None.

Variables assigned inside a function are local to that function unless they
are declared global. A local variable cannot normally be read outside the
function in which it was created.

Default parameter values are used when the caller omits the corresponding
argument. Parameters with default values must come after parameters without
default values in a function definition.

Python functions can be assigned to variables and passed as arguments to
other functions because functions are objects.
