# Master rad

Ovo implementacija veb aplikacije za master rad na temu **Projektovanje i evaluacija sistema za automatsko generisanje pitanja za proveru znanja primenom velikih jezickih modela**.


Glavni posao ove veb aplikacije  je da pomogne u generisanju pitanja sa višestrukim izborom od kojih je samo jedan tačan radi provere znanja. Nakon generisanja moguće je izmeniti pitanja, dodati nova i obrisati postojeća. Na kraju se radi evaluacija gde može da se oceni kvalitet generisanih pitanja.

## Arhitektura

Projekat se sastoji od backend i frontend dela. Frontend je radjen u Reactu, dok je backend radjen sa Python/FastAPI. Baza podataka je napravljena uz pomoć SQLite, nalazi se na backendu.
